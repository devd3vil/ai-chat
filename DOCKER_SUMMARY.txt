================================================================================
                      📖 TROUBLESHOOTING QUICK LINKS
================================================================================

"Port 8000 already in use?"
  → Change to "8001:8000" in docker-compose.yaml
  
"Ollama not responding?"
  → Check: docker-compose logs ollama
  → Wait longer for startup
  
"Out of disk space?"
  → Run: docker system prune -a --volumes
  
"Container keeps crashing?"
  → Check logs: docker-compose logs
  → Restart: docker-compose restart [service]
  
"Can't connect to Ollama?"
  → Verify: docker-compose exec app curl http://ollama:11434/api/tags
  
"First response taking forever?"
  → This is NORMAL - model is loading
  → Wait 30-60 seconds
